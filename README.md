# Ahana Chaudhury — Portfolio

Personal portfolio site for [Ahana Chaudhury](https://github.com/ahanachau99-glitch), modeled on the layout and interactions of [divyangmishra.github.io](https://divyangmishra.github.io).

Live URL after GitHub Pages is enabled:

https://ahanachau99-glitch.github.io/ahanachau99-glitch/

## Enable GitHub Pages

1. Open the repository on GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, set **Source** to **GitHub Actions**.
4. Wait for the **Deploy GitHub Pages** workflow to finish.

Alternatively, set Source to **Deploy from a branch**, branch `main`, folder `/ (root)`.

## Contact form

The contact form sends messages to **ahana.chau99@gmail.com** via FormSubmit.

The first time a message is sent, FormSubmit emails that inbox a one-time confirmation link. After that link is clicked, later submissions arrive as normal emails.
